ANALYSIS MODULES

One workflow. Multiple environmental indicators.

Choose a country, select an EarthLungs site, choose the analysis period and run the required analysis.

01

NDVI

10 m vegetation condition using Sentinel-2 surface reflectance.

02

NDRE

Baseline versus current change for NDVI and NDRE.

05

Dynamic World land-cover classification with confidence screening.

06

EVI

10 m enhanced vegetation index for vegetation response.

07

NDWI
