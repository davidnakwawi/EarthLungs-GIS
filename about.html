ABOUT EARTHLUNGS GIS

EarthLungs Spatial Intelligence Platform

GIS, remote sensing and drone mapping supporting EarthLungs restoration sites across Africa.

Purpose

EarthLungs GIS provides a structured spatial environment for viewing approved EarthLungs site boundaries and running repeatable remote sensing analyses for selected sites.

Current Coverage

The current production platform is connected to EarthLungs sites in:

  • Kenya
  • Tanzania
  • Mozambique

How the Platform Works

01 Country Select Kenya, Tanzania or Mozambique.
02 EarthLungs Site Select the approved site boundary.
03 Analysis Select the required spatial analysis.
04 Date Select the exact analysis dates.
05 Run Generate the selected analysis.

Current Analysis Scope

NDVI

Normalized Difference Vegetation Index for vegetation condition monitoring.

NDRE

Normalized Difference Red Edge for vegetation response using Sentinel-2 red-edge information.

NDVI + NDRE Comparison

Comparison of NDVI and NDRE for the selected EarthLungs site across analysis periods.

Temporal Change

Baseline versus current temporal change analysis for NDVI and NDRE.

LULC

Land-use and land-cover analysis using Google Dynamic World V1 with confidence screening.

EVI

Enhanced Vegetation Index for vegetation response.

NDWI

Normalized Difference Water Index for water and moisture-related surface response.

Interpreting Results

NDVI

Higher values generally indicate greener, denser vegetation. Use temporal change analysis to compare the same site across periods.

NDRE

Provides a red-edge vegetation signal and supports assessment of vegetation response where canopy condition varies.

EVI

Provides an enhanced vegetation response using near-infrared, red and blue bands.

NDWI

Provides a water and vegetation-moisture signal derived from green and near-infrared bands.

LULC

Dynamic World classes are screened using the production confidence threshold before class-area statistics and change mapping are reported.

Temporal Change

Compares baseline and current periods for NDVI and NDRE using absolute and percentage change.

Technology

The presentation website is hosted separately from the GIS analysis engine. The website provides documentation and access to the application; the EarthLungs GIS Application performs the spatial analysis using approved EarthLungs country site assets.

Sentinel-2 vegetation-index analysis uses COPERNICUS/S2_SR_HARMONIZED.

Land-cover analysis uses GOOGLE/DYNAMICWORLD/V1.

Platform Architecture

GIS Analysis
