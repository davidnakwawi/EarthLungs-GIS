ABOUT EARTHLUNGS GIS

Built around real site boundaries.

GIS, remote sensing and drone mapping supporting EarthLungs restoration monitoring.

Purpose

EarthLungs GIS provides a structured spatial environment for viewing EarthLungs site boundaries and running repeatable remote sensing analyses at selected sites.

Our Mission

To restore and protect ecosystems, fostering biodiversity and sustainable livelihoods through community-driven restoration and conservation efforts, ensuring a greener, healthier planet for present and future generations.

Our Vision

To be a leader in transforming Africa into a green, sustainable, and climate-resilient continent.

Current analytical scope

The production application currently provides NDVI, NDRE, NDVI + NDRE Comparison, Temporal Change, LULC, EVI and NDWI.

Interpreting Results

NDVI

Higher values generally indicate greener, denser vegetation. Use change analysis to compare the same site across periods.

NDRE

Provides a red-edge vegetation signal and is useful for evaluating vegetation response where canopy condition varies.

EVI

Provides an enhanced vegetation response using NIR, red and blue bands, especially useful where vegetation structure and background effects matter.

NDWI

Provides a water and vegetation-moisture signal derived from green and NIR bands.

LULC

Dynamic World classes are screened using the composite confidence threshold before class-area statistics and change mapping are reported.

Temporal Change

Compares baseline and current periods for NDVI and NDRE using absolute and percentage change.

Technology

The presentation website is hosted separately from the GIS analysis engine. The website provides documentation and access to the application; the EarthLungs GIS application performs the spatial analysis using approved EarthLungs country site assets and Sentinel-2 / Dynamic World datasets.
