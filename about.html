ABOUT

EarthLungs GIS

GIS, remote sensing and drone mapping for EarthLungs restoration sites.

Purpose

EarthLungs GIS provides a structured spatial environment for viewing EarthLungs site boundaries and running repeatable remote sensing analyses at selected sites.

Current analytical scope

The current production application covers NDVI, NDRE, NDVI + NDRE comparison, temporal change, Dynamic World land-cover analysis, EVI and NDWI.

Data workflow

01CountryKenya, Tanzania or Mozambique
02SiteSelect an EarthLungs boundary
03PeriodSelect exact analysis dates
04RunGenerate the selected analysis

Technology

The presentation website is hosted separately from the GIS analysis engine. The website provides documentation and access to the application; the EarthLungs GIS application performs the spatial analysis.

Current status: Production web interface connected to the published EarthLungs GIS application for Kenya, Tanzania and Mozambique.
